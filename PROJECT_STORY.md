# The 3D Shop Story 🎨

## A Fully Vibe Coded Project

This is the tale of **3D Shop** — a full-stack web application built entirely on vibes, intuition, and the energy of continuous iteration. No overengineering, no endless planning documents, just **building what felt right**.

---

## The Vision

What started as a simple idea evolved into a complete e-commerce platform for 3D printing services. A place where customers can browse, customize, purchase, and track their 3D-printed products. No overthinking. Just building.

---

## The Stack (Organically Chosen)

### Frontend ⚛️
- **React** + **TypeScript** — because type safety feels good
- **Vite** — fast, lean, no bloat
- **i18n** — internationalization for vibing with global audiences
- **Custom Services Layer** — built as needed, not pre-planned

### Backend 🔧
- **ASP.NET Core 8** — solid, performant, built with .NET's elegant defaults
- **Entity Framework Core** — data layer that just works
- **JWT Authentication** — brought in when security mattered
- **RESTful API Design** — endpoints that evolved naturally

### Database 🗄️
- **SQL Database** with EF Core migrations tracking every evolution
- 20+ migrations showing the organic growth of the schema
- From initial models → cart system → order management → admin functionality

---

## The Journey (In Commits)

Built through **25+ vibe-coded commits**, each one a chapter:

- Started with core **Products** and **Authentication**
- Added **Cart System** when it felt natural
- Evolved into **Orders** with pricing logic
- Implemented **Payment Processing** 
- Created **Admin Dashboard** for order management
- Built **Discount System** for business needs
- Hardened **Security** as the project matured
- Continuously refactored based on **what felt right**

No rigid specs. No Jira tickets. Just developers building, feeling the codebase breathe, and shipping features that make sense.
